NAVIGATION LAB / PRUEBA EXTERNA

Este enlace abre otra app.

Estás en Chrome, no dentro de Flutter. Pulsa un enlace para que Android abra la demo.

Primero instala la app con flutter run (main.dart o main_nav2.dart), o flutter run -t lib/main_nav3.dart para la versión con go_router. Usa esta página desde Chrome en el emulador Android.

1. Ir directamente a un producto

Resultado: detalle del producto 42. Al volver atrás verás Productos y luego Inicio.

Abrir producto 42 navdemo://app/products/42

2. Abrir una pantalla privada

Sin sesión: primero Login, después Perfil. Con sesión: directamente Perfil. La sesión es simulada y se pierde al reiniciar el proceso.

Abrir mi perfil navdemo://app/profile

3. Un enlace equivocado

Resultado: una pantalla 404 que explica el error y ofrece volver al inicio.

Probar enlace roto navdemo://app/no-existe

Prueba con la app cerrada y luego con ella abierta. Pegar texto en cualquier app no lo abre automáticamente: se necesita una app que permita pulsar enlaces de este tipo.
